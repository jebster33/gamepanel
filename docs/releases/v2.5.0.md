## GamePanel 2.5.0

**Look and feel**
- Sign-in and dashboard animate in, pages fade between routes, live values glow when they change.
- Loading screens are skeletons shaped like the page instead of a spinner or an empty box.
- Every emoji icon is now a drawn icon; a dropped connection says "Cannot reach the panel" or "You are offline".

**Security**
- Signing out really ends a session (a token with extra text added no longer works); open pages close when their API key or session is revoked.
- New recovery codes need a 2FA code. Read-only API keys cannot reach other nodes. Scheduled backups only delete old backups for people allowed to.
- Activity log and player search respect per-server permissions.
- Files a game plants in its folder (pipes, links) can no longer hang the panel; push subscriptions refuse redirects.

**Reliability**
- The panel's saved state is flushed to disk, keeps a `.bak` copy and restores from it after a power cut. An unreadable file stops the panel instead of being replaced.
- `GET /api/health` for uptime monitors (503 when the panel cannot save).
- Bad URLs and bodies get a 400, bugs show a reference code instead of internals.
- A game's RCON or status port can no longer freeze the panel; a stalled WebSocket client is dropped; deleting a server twice at once no longer removes another server; Docker or node connections that drop mid-answer fail cleanly.

Windows: run `GamePanel-Setup-2.5.0.exe`, or unzip the portable copy and run `start.cmd`. Linux panels update from Settings, or with `update.sh`.
